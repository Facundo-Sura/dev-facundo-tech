# Portfolio Personal

¡Bienvenido a mi portfolio personal! Este proyecto muestra mis habilidades y proyectos como desarrollador web fullstack. Aquí encontrarás información sobre mí, mis proyectos destacados, las tecnologías que utilizo y cómo contactarme.

## Tecnologías Utilizadas

- **Frontend:**

  - HTML, CSS, JavaScript
  - TypeScript
  - React.js, Next.js
  - Redux (para gestión del estado)
  - Tailwind CSS, Bootstrap (para estilos)

- **Backend:**

  - Node.js, Express (para la creación de APIs)
  - Nodemon (para el desarrollo en Node.js)
  - PostgreSQL, MySQL (bases de datos relacionales)
  - MySQL Workbench (para gestión de bases de datos)

- **Otros:**
  - Java (lenguaje de programación)
  - JDBC, JPA (para conexión y gestión de bases de datos en Java)

## Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

- **`/src`**: Contiene el código fuente de la aplicación.

  - **`/components`**: Componentes reutilizables de React.
  - **`/pages`**: Páginas de la aplicación (usando Next.js).
  - **`/styles`**: Archivos de estilos (CSS, Tailwind, Bootstrap).
  - **`/api`**: Endpoints de la API (Node.js y Express).
  - **`/database`**: Configuración y scripts de la base de datos.

- **`/public`**: Archivos estáticos como imágenes, fuentes, etc.

- **`/config`**: Configuración del proyecto (base de datos, variables de entorno, etc.).
